How its calculated split changes

The target’s own half is excluded from its incoming update. Only destinations receiving both halves are listed. Damping of the destination is common to the two incoming coefficients.

First-half share = 100 × p a / [p a + (1 − p) b]

p is the original split; a and b are the applied message coefficients. 50% indicates coefficient compensation for the original scaling. This diagnostic is not a changed cost split, nor evidence that the full nonlinear messages contribute equally. The current DABP attention parameterization restricts possible coefficient ratios; large compensation may be unreachable.

Compute the weights

Graph features + message history → GRU memory → 4 graph-attention layers → 4 attention/damping heads.

Head averages give the attention share α, new-message weight β, and old-message damping λ. β + λ = 1.

In this two-variable example, only one incoming message is eligible for each outgoing update: d = 1 and α = 1, so its applied coefficient c = d × α × β = β. The numerical β and λ are produced by the neural network each iteration.
